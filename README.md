
# TP Architecture Decision Records - Bibliothèque

Ce projet contient la documentation des décisions architecturales pour le système de gestion de bibliothèque.

## Structure

Les ADR sont situés dans le dossier `doc/adr/`.

## Comment contribuer

1. Copier le template d'ADR existant.
2. Créer un nouveau fichier `doc/adr/XXXX-titre-decision.md`.
3. Remplir les sections (Statut, Contexte, Décision, Conséquences).
4. Exécuter le script de validation avant de commiter.

## Validation

Utilisez `./scripts/validate_adr.sh` pour vérifier le format des fichiers.
